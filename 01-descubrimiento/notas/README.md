# Notas de descubrimiento

Una nota por reunión o entrevista. Nombre: `AAAA-MM-DD-tema.md`.
Plantilla: `../../_plantillas/nota-reunion.md`.

Las notas son materia prima, no fuente de verdad: lo que quede en firme se promueve a
`00-contexto/` o `02-producto/`, y lo que quede en el aire se abre como `PA-xxx`.

Las sesiones a agendar están en [`../plan-de-definicion.md`](../plan-de-definicion.md).
