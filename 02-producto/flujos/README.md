# Flujos

Flujos end-to-end del producto, uno por archivo: `FL-xxx-nombre.md`.
Plantilla: `../../_plantillas/flujo.md`.

Un flujo describe el recorrido completo de un actor para lograr un objetivo, con sus
caminos alternos y de error. Es el puente entre una capacidad y sus historias.
