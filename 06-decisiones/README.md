# Decisiones (ADR)

Una decisión con alternativas y consecuencias = un ADR. Archivo: `ADR-0001-titulo.md`.
Plantilla: `../_plantillas/adr.md`.

Un ADR no se edita cuando cambia la decisión: se escribe uno nuevo que lo reemplaza, y el
viejo pasa a estado `reemplazado` apuntando al nuevo.
